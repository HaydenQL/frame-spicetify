# FRAME for Spicetify

FRAME is a personal Spotify customization project built for the Spicetify ecosystem. It provides a workspace-oriented interface for organizing and accessing music collections.

## Features

- Custom workspaces and pinned music shortcuts
- Playlist and artist navigation
- Drag-and-drop organization
- Interface customization and layout controls
- GitHub-hosted release and update workflow

## Project status

This is an independently developed, AI-assisted project. Features and compatibility may vary across Spotify and Spicetify versions. Review the source code and release notes before installing.

## Development

The project was built iteratively with AI-assisted implementation, hands-on testing, troubleshooting, and version management. It is presented as a personal software project, not as professional employment experience.

## Security and privacy

This project is not affiliated with Spotify or Spicetify. Only install releases you trust, and review requested permissions and scripts before running them.
